# SiteSense-5G

## Overview

Use this repository to collect your project code, notebooks, datasets, and documentation.

## Getting Started

1. Add your project files to this repository.
2. Commit your changes with a short message that explains what changed.
3. Push your work back to CollabHub so your team can see it.

## Suggested Folders

- `data/` for sample datasets or data notes
- `notebooks/` for experiments and analysis
- `src/` for source code
- `docs/` for project documentation
